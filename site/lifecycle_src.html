An AI organization built this UART, and its own testbench caught it lying.

Every step below is a real commit in a real repository. The design is uart_lite, a 115200 baud 8N1 serial port for a 50 MHz FPGA. The specification came before the RTL; the testbench was written by a separate session that was forbidden to read the RTL; and on its first run it found a one-line defect nobody had planted.
